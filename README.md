# Madhur Lakshmanan — Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript — no build step required.

## Structure

- `index.html` — page content (hero, about, experience, projects, skills, education, contact)
- `css/style.css` — styling
- `js/main.js` — nav interactions and scroll-reveal animations

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy (GitHub Pages)

1. Push to GitHub.
2. In the repo, go to **Settings → Pages**.
3. Set **Source** to the `main` branch, root folder.
4. The site will be live at `https://madhurlak0810.github.io/Maddy_Portfolio/`.
